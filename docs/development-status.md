## 다음 단계의 완료 기준(예정)

1. **T2 대표 4개 모델:** 서로 다른 종족별 단일 입력, GLB 저장, Blender 검수 이미지 저장.
2. **BODY·HEAD:** 동일 치수의 목 접합 기준 정의 및 교차 장착 테스트.
3. **분대 RTS:** 선택/이동/공격이동/후퇴를 테스트 시나리오별 PASS 로그로 증명.
4. **진화 트리:** 상위 노드 변경 시 하위 선택 초기화, 조건 미달 노드 비활성 처리 테스트.
5. **포트폴리오 증빙:** 엔진 플레이 캡처, 자체 제작 모델 사례, 명시적인 버전/테스트 정보 추가.
