# Creature War | 1-page 프로젝트 개요

**핵심 컨셉:** 직접 설계한 생물을 편성해 대규모 계층형 RTS 전쟁에 참가하고, 전쟁의 성과로 다음 진화를 해금하는 게임.

**장르 / 목표:** 생물 제작·진화 × 분대 RTS × 전략·전술 다중 지휘. 현재 개발 중이며 완성 게임/상용 온라인 서비스가 아님.

## 핵심 플레이 루프

**진화 설계(T0~T5) → BODY·PART·ORGAN 구성 → Blueprint/로스터 저장 → War COST로 출격 편성 → 전략·전술·분대 전쟁 수행 → 손실/임무/승패 정산 → Evolution Currency(EC) 획득 → 해금/재설계.**

생물은 전쟁 전에 제작합니다. T0부터 전쟁에 참여할 수 있습니다. 고티어만 유리한 대신 저티어가 물량·유지비·정찰·작업 효율에서 선택의 의미를 갖도록 설계합니다.

## 게임의 구조

- **제작:** 4대 체형/16종족. BODY=신체 구조, PART/HEAD=공격·이동·탐지·방어 수단, ORGAN=신경·대사·공급. 역할은 고정 클래스가 아님.
- **전략:** 전쟁 전체 목표, 점령과 전쟁 경제/시설, War COST 배분.
- **전술:** 섹터, 임무, 파견, 경로/시설/보급, 전략 명령의 현장화.
- **분대 RTS:** 생물/그룹 선택, 이동·공격이동·정찰·공병. 개체 AI는 실제 공격과 국소 이동을 보조.
- **성장:** 임무/승패/손실 결과를 EC와 새로운 진화·기관 해금에 반영.

## 네트워크 구축 방향

**기획에서 확인된 원안:** 상시 서버 비용을 줄이려는 P2P/호스트 기반. 20대20/30대30은 목표로 검토한 규모, **실제 부하·동기화 검증 전**.

**후보 설계:** 가벼운 세션 탐색/연결 보조 + 매치 권한 호스트에서 명령 검증/상태 적용 + 전략·전술 이벤트와 분대 전투 상태의 구분된 전파 + 정찰 정보 접근 제한. NAT/릴레이, 결정론, 치트 방지, 호스트 이탈, 재접속, 영구 보상 검증을 테스트한 뒤 아키텍처를 확정.
