# 프로젝트 요약 | Creature War

**한 문장:** 생물 구조를 직접 설계하고, 설계 결과가 전술 행동으로 연결되는 분대 RTS.

## 해결하고 싶은 문제

게임의 육성 선택이 단순히 공격력 수치만 바꾸면, 플레이어가 설계한 생물의 개성이 전투 방식으로 이어지기 어렵습니다. 이 프로젝트는 체형·외부 파츠·내부 기관을 구분하고, 조합에 따라 이동·공격·정찰·작업 가능성이 달라지게 하는 방향을 실험합니다.

## 핵심 경험

**설계 → 편성 → 지휘 → 전투 결과 분석 → 재설계**. 플레이어는 분대를 지휘하고 개체는 선택된 공격수단과 몸 구조에 맞춰 세부 행동을 실행합니다.

## 중요한 설계 판단

1. **단일 트리:** T0~T2 종족 경로 후 T3 공통 전술 역할과 T4 수행 방식으로 분기.
2. **책임 분리:** BODY=구조 및 허가, PART=수행 수단, ORGAN=생리와 제어, ROLE=전술 특화.
3. **역할 비고정:** 같은 종족도 보급·정찰·근접·공병 등 복합 운용 가능.
4. **지휘권 유지:** RTS 플레이어가 이동·목표·우선순위를 지정하고 개체 AI가 국소 실행 담당.
5. **검증 우선:** 모델 생성은 별도 QC를 통과해야 엔진 자산으로 승인.

## 공개 데이터

16종족 × (T0 1 + T1 4 + T2 12) = **272개 기본 진화 노드**. 이 중 **4족형 68개**를 재현 가능한 데이터 샘플로 제공합니다. T3 9개 역할, T4 36개 운용 방식은 설계 경로 정의입니다. T5 후보 ID 592개는 완성 모델 수를 뜻하지 않습니다.

## 현재 주의사항

Unreal Engine 5.8로 개발을 진행하고 있으나, 이 공개 저장소에는 전체 Unreal 소스가 없습니다. 따라서 전투 동작, 모든 종족 모델, 자동 결합 품질에 대한 완성·검증 주장을 하지 않습니다.
