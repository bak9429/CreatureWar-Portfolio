# 공개 데이터 샘플

본 폴더는 이력서용으로 공개 가능한 **데이터 구조 샘플**만 포함합니다. Unreal의 원본 `Content`, 게임 소스, 상용 자산, Trellis GGUF 모델은 포함하지 않습니다.

| 파일 | 범위 | 참고 |
|---|---|---|
| `species_summary.csv` | 16종족·T0~T2 합계 | 16×17 노드 |
| `quadruped_nodes_sample.csv` | Q01~Q04, 68행 | T0 4·T1 16·T2 48 |
| `role_paths.csv` | T3 9개·T4 36개 | 공통 역할 분기 |

`modelStatus`는 메시 파일의 성공적인 생성 여부가 아니라 현재 원본 CSV의 관리 상태입니다. `GEOMETRY_REVIEW_REQUIRED`는 모델 완성을 의미하지 않습니다. `T5` 후보 ID 592개는 별도의 경로 명세에서 집계한 **설계상 식별자**이며 완성된 모델 수가 아닙니다.

원본 파일과 비교하는 범위에서 공개 정보의 의미를 유지했지만, 모델 경로 등 내부 파일 경로는 의도적으로 제외했습니다.
